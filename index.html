01

你说一句话

自然语言描述需求——"加个 JWT 登录"、"修这个 bug"、"重构这块"。 Agent 自动理解意图并规划执行路径，最多 20 次工具调用迭代。

02

Agent 自主调用工具

23 个内置工具可被自由组合：read_file / grep / list_files / run_command / edit / web_search / sub_agent … 流式工具调用——参数实时透传，文件写入过程即时可见。

03

代码写入项目

Hash-Anchored Edit 用 SHA3-8 行哈希消除 stale-line 错误。 AST-Grep + LSP 提供代码智能：诊断、跳转、引用、重命名一应俱全。

04

桌宠为你庆祝

任务完成后桌宠切换开心表情与动作。LLM 根据对话内容自动选择最合适的动作，让角色"活"起来。 开启 TTS 让 AI 伴侣用声音与你交流。
